# Рабочие копии и черновики агентов

Здесь заводятся worktree полос, логи прогонов и черновики. Каталог **игнорируется**
git и в поставку не входит; отслеживается только этот файл.

Почему не `/tmp`: он эфемерен и чистится системой, а на этой машине смонтирован в
память. Работа, лежащая там незакоммиченной, существует в одном экземпляре и
пропадает без следа — это уже случалось. Здесь она переживает перезагрузку и видна
переписи веток (`scripts/branch-audit.sh`).

Путь рабочей копии задаётся **абсолютным**: `git -C project/kacho` меняет рабочий
каталог, и относительный путь развернётся от дерева продукта, а не оттуда, откуда
команда набрана.

Убирать за собой обязательно: `git worktree remove <путь>` по окончании полосы.
