# PlacementGroup

**PlacementGroup** — правило взаимного размещения машин.

Вы просите **разнести** машины либо **сблизить** их. Разнести — чтобы отказ одного куска
железа не унёс всю группу; сблизить — чтобы машины видели друг друга коротким путём. Это
ровно два намерения, и оба выразимы без единого числа.

:::info Числа доменов отказа здесь нет — намеренно
«Разнести на N доменов отказа» звучит точнее и является хуже: число описывает **нашу**
раскладку железа, а не ваше намерение. Опубликовав его, платформа обязалась бы держать эту
раскладку неизменной — и потеряла бы право менять собственную инфраструктуру, ничего не
сломав снаружи. Число остаётся решением исполнителя.
:::

## Якорь размещения

Группа либо **зональная** (машины в одной зоне), либо **региональная** (машины в одном
регионе, зоны разные). Это дискриминатор, а не пара необязательных полей: строка, где
заполнены обе координаты, описывала бы размещение, которого не бывает, и закрыто это
проверкой схемы БД, а не дисциплиной вызывающего.

<StatusTable values={[
  { code: 'ZONAL', desc: 'Задан zoneId, regionId пуст' },
  { code: 'REGIONAL', desc: 'Задан regionId, zoneId пуст' },
]} />

:::warning Машина обязана быть когерентна якорю группы
Зональная группа принимает машины **своей зоны**; региональная — машины **своего региона**.
Несовпадение отвергается на `Instance.Create` и `Instance.Update`, а не обнаруживается
позже: группа, в которую попала машина не оттуда, не выполняет ни одного из двух обещаний.
:::

`strategy`, `placementType` и координата якоря задаются на создании. Смена стратегии — это

объявить исполненным то, что исполнено не будет. Меняются свободно `name`, `description`,
`labels`.
:::

## Create

<ApiOperation method="POST" endpoint="/compute/v1/placementGroups">

Заводит группу. Мутация асинхронна — идентификатор лежит в `metadata.placementGroupId`
возвращённой `Operation`.

  <thead><tr><th>Поле</th><th>Обязательно</th><th>Тип</th><th>Описание</th></tr></thead>
