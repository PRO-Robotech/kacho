**notify** — шлюз уведомлений платформы Kachō. Это единственный процесс установки, который
держит креды почты. Письма он не принимает вызовом: он сам забирает их из лент служб-источников,
по каждому письму спрашивает право у службы управления доступом и отправляет письмо через
ретранслятор установки.

## Поверхность службы

| Что | Как устроено |
|---|---|
| Входящий API | нет: gRPC-сервисов notify не обслуживает и gRPC-слушателя не поднимает |
| Диагностика | HTTP `/healthz`, `/readyz`, `/metrics` на адресе ручки `KACHO_NOTIFY_DIAG_ADDR`, доступном только внутри кластера |
| Настройка | переменные окружения `KACHO_NOTIFY_*` без умолчаний: незаданная обязательная ручка или значение вне границы останавливает старт, и текст отказа называет ручку |
