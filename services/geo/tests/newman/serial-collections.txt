# Collections that mutate the GLOBAL geo catalog (Region/Zone are cluster-singletons,
# not project-scoped → cannot be {{runId}}-isolated). The public read collections
# region.py / zone.py "List all → pick [0] → Get it"; if an internal-* collection
# creates/deletes catalog rows concurrently, the picked row can vanish mid-flight
# (Get → 404 → undefined-field asserts). Defer these to run strictly after the
# parallel pool, one at a time — same pattern as vpc EXTERNAL AddressPool (#59).
#
# Membership rule: a stem belongs here iff it issues a POST/PATCH/DELETE against
# /geo/v1/internal/{regions,zones} that is EXPECTED TO SUCCEED. A mutating verb that
# asserts 401/403 changes nothing in the catalog and does NOT belong (see authz-deny
# below). Default auth in gen.py is jwtBootstrap, which carries system_admin@cluster —
# so a mutating step WITHOUT an explicit non-admin `auth=` override does land.

# Admin CRUD suites — the original two. Region/Zone create+update+delete throughout.
internal-region
internal-zone

admin-not-on-public
