# DiskType

**DiskType** — позиция каталога типов диска: класс надёжности и производительности, из
которого выбирают при создании тома. Каталог глобальный и курируется администратором
платформы; тенант его только читает.

:::info Идентификатор — slug, а не сгенерированный ключ
`DiskType` — единственный ресурс сервиса, чей идентификатор **не генерируется**: это
читаемый slug (`block-balanced`), назначаемый администратором. Причина в том, что это
позиция справочника, а не созданный тенантом ресурс: на неё ссылаются в запросах руками,
и осмысленное имя здесь полезнее непрозрачного ключа.

Это не отступление от правила «адресация по неизменяемому идентификатору»: slug и
**есть** первичный ключ, он неизменен и не переименовывается.
:::

## Состав каталога

| id | `performanceTier` | Назначение |
|---|---|---|
| `block-standard` | `standard` | Экономичный надёжный том |
| `block-balanced` | `balanced` | Сбалансированный, общего назначения |
| `block-fast` | `fast` | Высокий IOPS, низкая задержка |
| `block-single` | `single` | Однорепличный, без резервирования |
| `block-io-max` | `io-max` | Максимальные IOPS и пропускная способность |

Названия описывают класс надёжности и производительности. Обратите внимание на
`block-single`: он **не реплицирован**, и это единственная ступень каталога без
резервирования — выбирать её осознанно.

## Кто это читает

Каталог — глобальный справочник: чтобы завести хоть один том, тенант обязан знать
доступные типы. Поэтому чтение доступно **каждому аутентифицированному** субъекту и через
фильтр видимости не проходит — у позиций каталога нет индивидуальных владельцев.

Аутентификация при этом обязательна: анонимный запрос отвергается.

## Администрирование

Создание, изменение и удаление позиций каталога живут в `InternalDiskTypeService` на
**внутреннем листенере** и на публичную поверхность не выведены. В отличие от остальных
ресурсов, эти методы **синхронны** — возвращают сам ресурс, а не операцию.

Подробнее — [Внутренний API](/api/internal).

## Что блокирует удаление типа

Тип, на который ссылается хотя бы один том, удалить нельзя: это держит внешний ключ
`volumes.disk_type_id → disk_types` с поведением `RESTRICT`.
