# Наблюдаемость

Эта страница — то, чем пользуется дежурный: какие величины край отдаёт о своих отказах, что
означает каждая, какие правила тревоги поставляются вместе с чартом и в каком порядке разбирать
сработавшее правило.

## Куда смотреть

| Адрес | Что отдаёт |
|---|---|
| `:9095` `/metrics` | величины в формате Prometheus; адрес задаёт `KACHO_API_GATEWAY_METRICS_ADDR` |

Порт внутренний: наружу он не публикуется.

## Ограничитель анонимной почты

Запрос без удостоверения, ведущий к отправке письма, край пропускает через ограничитель. Решение
ограничителя хранится в базе, общей для всего флота края. Если база не дала ответа в срок,
запрос получает закрытый отказ `503` с текстом `request limiter is unavailable` — до службы
личности он не доходит, и письмо не уходит. Пропустить запрос без решения край не вправе: тогда
ограничитель не ограничивал бы ничего.

| Величина | Что считает |
|---|---|
| `kacho_api_gateway_anon_mail_store_unavailable_total` | все ответы `503` ограничителя с запуска процесса: хранилище не ответило в срок либо исход фиксации решения не удалось установить |
| `kacho_api_gateway_anon_mail_bucket_wait_timeouts_total` | из них — те, где решение не получило общее ведро потока в срок: поток выше пропускной способности решения флота (насыщение) |

Вторая величина — подмножество первой. Разность между ними — отказы самого хранилища, не
связанные с насыщением. Обе серии объявлены с запуска процесса: ноль отказов и отсутствие сбора
различимы без единого запроса.

**Насыщение — принятая цена, а не дефект.** Поток выше пропускной способности решения кончается
закрытым отказом намеренно. Цена принята при условии, что она видна, — поэтому для неё есть
отдельная серия и отдельное правило.

## Правила тревоги

Правила поставляются объектом `PrometheusRule` чарта края — переносить их руками не нужно. Ниже —
ровно то, что везёт объект; страница и объект сверяются проверкой в обе стороны.

```yaml
- alert: KachoApiGatewayAnonMailSaturated
  expr: sum(increase(kacho_api_gateway_anon_mail_bucket_wait_timeouts_total[10m])) > 0
  for: 5m
  annotations:
    summary: "ограничитель анонимной почты насыщен: решения флота не получают общее ведро, запросы закрыты отказом 503 и письма не уходят"

- alert: KachoApiGatewayAnonMailStoreUnavailable
  expr: sum(increase(kacho_api_gateway_anon_mail_store_unavailable_total[10m])) > 0
  for: 5m
  annotations:
    summary: "ограничитель анонимной почты отвечает 503: хранилище не ответило в срок либо исход фиксации не разрешён; насыщение входит сюда же"
```

**Порог — первый отказ за окно.** Это консервативный выбор: измеренной пропускной способности
решения ограничителя для конкретного флота нет, и порог в доле отказов выбрать не из чего. Когда
нагрузочный прогон даст это число для вашего флота, порог переводят в долю отказов от потока.

### Как выключить

`PrometheusRule` — вид оператора Prometheus. Где его определения в кластере нет, объект
отвергнет вся установка, а не одно правило. Такая установка выключает объект:

```text
alertRules.enabled: false
alertRules.disabledBecause: "<почему: например, оператора Prometheus на кластере нет>"
```

Причина обязательна: выключение без неё чарт отвергает при рендере, потому что невыставленная
тревога молчит так же, как исправный ограничитель.

### Разбор сработавшего правила

1. **Сработало только `…StoreUnavailable`, без `…Saturated`.** Отказывает само хранилище: проверьте
   доступность базы края и журнал края: строки уровня `WARN` с префиксом `anon mail limiter:`
   называют отказавший шаг (поле `step`) либо неразрешённый исход фиксации.
2. **Сработали оба.** Поток анонимных запросов упёрся в пропускную способность решения. Сравните
   поток запросов, ведущих к письму, с обычным для этого времени: всплеск без роста
   регистраций — признак перебора, и закрытый отказ здесь работает как задумано; рост законного
   потока — повод нарастить ресурс базы края.
