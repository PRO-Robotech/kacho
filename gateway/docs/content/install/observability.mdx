# Наблюдаемость

Эта страница — то, чем пользуется дежурный: какие величины край отдаёт о своих отказах, что
означает каждая, какие правила тревоги поставляются вместе с чартом и в каком порядке разбирать
сработавшее правило.

## Куда смотреть

| Адрес | Что отдаёт |
|---|---|
| `:9095` `/metrics` | величины в формате Prometheus; адрес задаёт `KACHO_API_GATEWAY_METRICS_ADDR` |

Порт внутренний: наружу он не публикуется.

## Ограничитель анонимной почты

Запрос без удостоверения, ведущий к отправке письма, край пропускает через ограничитель. Решение
ограничителя хранится в базе, общей для всего флота края. Если база не дала ответа в срок,
запрос получает закрытый отказ `503` с текстом `request limiter is unavailable` — до службы
личности он не доходит, и письмо не уходит. Пропустить запрос без решения край не вправе: тогда
ограничитель не ограничивал бы ничего.

| Величина | Что считает |
|---|---|
| `kacho_api_gateway_anon_mail_store_unavailable_total` | все ответы `503` ограничителя с запуска процесса: хранилище не ответило в срок либо исход фиксации решения не удалось установить |
| `kacho_api_gateway_anon_mail_bucket_wait_timeouts_total` | из них — те, где решение не получило общее ведро потока в срок: поток выше пропускной способности решения флота (насыщение) |
| `kacho_api_gateway_anon_mail_bucket_hold_seconds_total` | секунды, пока решения процесса держали строку общего ведра — от получения строки до конца её транзакции |
| `kacho_api_gateway_anon_mail_clock_offset_seconds` | смещение часов реплики от часов базы ограничителя в последнем решении: момент решения минус время базы; плюс — реплика впереди |

Вторая величина — подмножество первой. Разность между ними — отказы самого хранилища, не
связанные с насыщением. Три счётчика объявлены с запуска процесса: ноль отказов и отсутствие сбора
различимы без единого запроса.

Строка общего ведра одна на установку, поэтому `sum(rate(…_bucket_hold_seconds_total[5m]))` по
всему флоту — доля времени, когда она занята, от 0 до 1. Эта доля растёт **до** первых отказов:
по ней видно приближение к насыщению, пока запас ещё есть. Строку берут только решения, которым
нужен жетон общего потока, — запросы без доказательства с открытой ступени; отказ по ключам
источника и пропуск по доказательству её не занимают.

Смещение часов отдаётся только после первого решения, которое его измерило; при хранилище в
памяти процесса часов базы нет, и величины нет вовсе. Момент решения берётся до захвата
соединения и блокировок, поэтому измерение может быть занижено не больше чем на срок решения
(1,5 с); значение больше нуля — всегда сдвиг часов реплики вперёд.

**Насыщение — принятая цена, а не дефект.** Поток выше пропускной способности решения кончается
закрытым отказом намеренно. Цена принята при условии, что она видна, — поэтому для неё есть
отдельные серии и правило, звонящее раньше отказов.

## Правила тревоги

Правила поставляются объектом `PrometheusRule` чарта края — переносить их руками не нужно. Ниже —
ровно то, что везёт объект; страница и объект сверяются проверкой в обе стороны.

```yaml
- alert: AnonMailBucketSaturation
  expr: sum(rate(kacho_api_gateway_anon_mail_bucket_hold_seconds_total[5m])) > 0.8
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "строка общего ведра ограничителя анонимной почты занята больше 80% времени: запас до закрытых отказов 503 исчерпывается"

- alert: AnonMailBucketExhausted
  expr: sum(rate(kacho_api_gateway_anon_mail_bucket_wait_timeouts_total[5m])) > 0
  for: 5m
  labels:
    severity: critical
  annotations:
    summary: "ограничитель анонимной почты насыщен: решения флота не получают общее ведро, запросы закрыты отказом 503 и письма не уходят"

- alert: AnonMailStoreUnavailable
  expr: (sum(rate(kacho_api_gateway_anon_mail_store_unavailable_total[5m])) - sum(rate(kacho_api_gateway_anon_mail_bucket_wait_timeouts_total[5m]))) > 0
  for: 5m
  labels:
    severity: critical
  annotations:
    summary: "ограничитель анонимной почты отвечает 503 не по насыщению: хранилище не ответило в срок либо исход фиксации не разрешён"

- alert: AnonMailClockSkew
  expr: max(abs(kacho_api_gateway_anon_mail_clock_offset_seconds)) > 2
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "часы реплики края расходятся с часами базы ограничителя больше чем на 2 с: окна счёта и ведро общего потока судятся сдвинутыми часами"
```

**Порог занятости `0.8` — ориентир до замера.** Доля занятости, при которой начинаются отказы,
зависит от времени удержания строки, а оно — от задержки до базы края; измеренного числа для
конкретного флота нет. Когда нагрузочный прогон ограничителя с двумя репликами даст долю занятости
в момент первого отказа по насыщению, порог ставят ниже неё. Число не переносится между
окружениями: другая машина, другой флот или другая задержка до базы — новый прогон и новый порог.

**Порог смещения часов `2` с выведен, а не выбран:** измерение занижено не больше чем на срок
решения (1,5 с), и полсекунды сверх него ожидание внутри решения не даёт — их даёт только сдвиг
часов. Сдвинутые часы реплики двигают окна счёта: реплика впереди пишет моменты пропуска в
будущее, и их считают все реплики; реплика позади недосчитывает на границе окна.

### Как выключить

`PrometheusRule` — вид оператора Prometheus. Где его определения в кластере нет, объект
отвергнет вся установка, а не одно правило. Такая установка выключает объект; выключатель один на
все чарты kacho и задаётся в общих значениях:

```text
global.kacho.alertRules.enabled: false
global.kacho.alertRules.disabledBecause: "<почему: например, оператора Prometheus на кластере нет>"
```

Причина обязательна: выключение без неё чарт отвергает при рендере, потому что невыставленная
тревога молчит так же, как исправный ограничитель.

### Разбор сработавшего правила

1. **`AnonMailBucketSaturation` (warning).** Строка общего ведра занята почти всё время, отказов
   по насыщению ещё нет. Сравните поток анонимных запросов, ведущих к письму, с обычным для этого
   времени: всплеск без роста регистраций — признак перебора; рост законного потока — повод
   нарастить ресурс базы края, пока отказы не начались.
2. **`AnonMailBucketExhausted` (critical).** Поток упёрся в пропускную способность решения, и
   анонимные запросы получают `503`. Порядок разбора — как в п. 1; закрытый отказ здесь работает
   как задумано, и письма на чужие адреса при переборе не уходят.
3. **`AnonMailStoreUnavailable` (critical).** Отказывает само хранилище, а не насыщение: проверьте
   доступность базы края и журнал края — строки уровня `WARN` или `ERROR` с префиксом
   `anon mail limiter:` называют отказавший шаг (поле `step`) либо неразрешённый исход фиксации.
4. **`AnonMailClockSkew` (warning).** Часы реплики расходятся с часами базы: проверьте синхронизацию
   времени на узле, где стоит реплика, и на узле базы. Значение больше нуля — реплика впереди базы.
