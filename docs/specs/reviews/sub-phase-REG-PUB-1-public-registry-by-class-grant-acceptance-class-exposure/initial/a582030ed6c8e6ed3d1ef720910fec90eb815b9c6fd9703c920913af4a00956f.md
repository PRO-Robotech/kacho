1. **Р1 / S1** — роль `registry.public.read` с вложенным правилом в манифесте registry; пин kaname ≥ `efac3adf7` и тег образа в 5 профилях; `system_class` в `subjectUsersets`; гейт края подстановочных отношений отличает подстановку от выдачи классу. Всё — в PR `kacho#3279`.
2. **Р2 / инвариант 5** — у registry нет представления публичности: ни поля, ни столбца, ни метода. Открытость задаёт только выдача.
3. **Р3** — открыть реестр может тот, кто вправе выдавать. Ворота kaname не меняются.
4. **Р7** — при удалении реестра выдача не отзывается. Отзыв — отдельным глаголом.
5. **Р9 п. 2 / S3** — новая ручка чарта registry (`anonymousSubjectId` → `KACHO_REGISTRY_ANONYMOUS_SUBJECT_ID`). Вложенный чарт kaname впервые выводит `anonymous-client-id`. Рендер отказывает на двух разных значениях.
6. **Р9 п. 3 / S4** — второй подъём пина kaname: не ниже `0b6b21cc9`, на ствол kaname. Профили стенда задают одно значение закрытой формы SC-39.
7. **Р9 п. 4 / S4** — новый шаг сквозного прогона с настоящим клиентом `docker`.
8. **Р10** — вошедший без прав видит метаданные открытого реестра через API-край, включая `List` по чужому проекту.
9. **DoD S2** — переписать тексты, которые доставка роли делает ложными. Комментарии proto, затем `buf generate`.
10. **DoD S2/S3** — переписать newman-кейсы ветки `3274` без `visibility`. Новые кейсы 02, 03, 13, 14, 20–27, 29.
11. **«Снятие прежнего объёма»** — RED-пробы прежнего объёма не попадают в дерево.
