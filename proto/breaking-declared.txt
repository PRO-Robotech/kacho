# Проверка совместимости про это решение не знает и роняет прогон. Исходов было

# КАК ЭТО ЧИТАЕТСЯ ПРОВЕРКОЙ (scripts/buf-breaking-declared.sh):
#   находка есть, строки нет   → ОТКАЗ. Незаявленный слом не проезжает.
#   находка есть, строка есть  → пропуск. Слом объявлен здесь и в коммите.
#   строка есть, находки нет   → ОТКАЗ. Записи больше нечего исключать.
#
# Последнее — не придирка, а то, ради чего перечень вообще может существовать.
# После вливания в ствол основание сравнения сдвигается, находки исчезают, и
# записи становятся ложью. Проверка обязана этого потребовать: перечень, который
# переживает свой предмет, молча прикроет следующий слом. Поэтому ВЛИВ ЭТУ ВЕТКУ,
# ОПУСТОШИТЕ ФАЙЛ — прогон следующего изменения не даст об этом забыть.
#
# Формат: «файл:строка:колонка:текст находки» — ровно как печатает проверка.
