# Осознанные СНЯТИЯ и ПРИСПОСОБЛЕНИЯ содержимого ствола при переносе — перечень
# С ПРЕДМЕТОМ.
#
# Имя файла ИСТОРИЧЕСКОЕ: заведён он под одни снятия, а с 17399329d4 покрывает и
# приспособления. Имя — координата, на которую ссылаются `drift.sh`, `judge.sh` и
# проба, поэтому оно оставлено; названо здесь, чтобы не читалось как объём.
#
# ЗАЧЕМ ЭТОТ ФАЙЛ. Гейт `drift.sh` стережёт молчаливый откат: ветка, отставшая от
# ствола, возвращает содержимое базы на файлах, которых не касалась, и конфликта
# при этом нет. Но у расхождения есть и законные случаи, и их ДВА:
#
#   СНЯТИЕ — ствол и ветка независимо завели ОДИН предмет разными файлами, и в
#   результате обязан остаться один; файл ствола снимается решением.
#
#   ПРИСПОСОБЛЕНИЕ — ветка ввела правило, под которое содержимое ствола перестало
#   быть законным входом (предел длины прозы, форма имени, обязательное поле), и
#   разрешавший слияние привёл его к новой форме. Файл на месте, содержимое новое.
#
# Различие с откатом не выводится из графа: по путям все три картины одинаковы.
# Поэтому решение называется здесь ЯВНО, по одному файлу на запись, с причиной.
#
# КАК ЭТО ЧИТАЕТСЯ ГЕЙТОМ — строки ПО ПОРЯДКУ, первая подошедшая и решает; без
# порядка две из них спорили бы на файле, которого не было ни в базе, ни в
# результате, а он и есть штатное снятие того, что завёл ствол:
#   находка есть, строки нет            → ОТКАЗ. Молчаливое расхождение не проезжает.
#   строка есть, файла в результате нет → пропуск: «снято решением».
#   строка есть, содержимое НОВОЕ       → пропуск: «приспособлено решением».
#   строка есть, содержимое равно БАЗЕ  → ОТКАЗ. Это откат, и объявление его не
#                                         покрывает — иначе строка стала бы
#                                         разрешением тихо отменять чужую работу.
#   строка есть, находки нет            → ОТКАЗ. Записи больше нечего исключать.
#
# Предпоследнее несущее: объявление не есть право править чужое. Последнее — не
# придирка: запись, пережившая свой предмет, прикроет следующее расхождение молча,
# и гейт останется зелёным ровно на том, ради чего писался. Поэтому запись
# УДАЛЯЕТСЯ тем же изменением, которое поднимает базу сравнения.
#
# Форма записи: <путь> <TAB или пробелы> <причина одной строкой>
#
# ПРЕЖДЕ ЧЕМ ДОБАВИТЬ ЗАПИСЬ — прочтите, чем она истечёт.
#
# Здесь стояло: «самоистечение судится ДИАПАЗОНОМ прогона (BEFORE..HEAD_SHA) …
# пока #1911 не закрыт, запись на накопительной линии делает ХУЖЕ, чем
# оставленная находка». Верно это было ровно до починки #1911 — и та же линия,
# которая её посадила, оставила предупреждение на месте. Утверждение пережило
# свой предмет и отговаривало от того самого механизма, ради которого перечень и
# заведён; это второй экземпляр класса, из-за которого правился комментарий над
# веткой приспособления (#1914).
#
# ЧТО ВЕРНО СЕЙЧАС. Диапазон ВЫВОДИТСЯ ИЗ ГРАФА: судятся все посадки линии сверх
# ствола, а не прирост отправки, поэтому запись живёт, пока покрываемая ею
# посадка достижима от вершины, и переживает любое число отправок. Перемерено на
# этом дереве в обе стороны: полный диапазон и суженный `BEFORE` дают ОДИН
# вердикт — 32 посадки, потому что на линии `BEFORE` не читается вовсе.
#
# ЧЕМ ЗАПИСЬ ИСТЕКАЕТ. Двумя способами, и оба дают код 3:
#   посадка достижима, а снятия или приспособления в ней больше нет — предмет
#   исчез, база сравнения поднялась;
#   посадка НЕдостижима — линия влита в ствол схлопыванием, и её коммитов в
#   графе не существует.
# Поэтому запись СНИМАЕТСЯ тем же изменением, которое вливает линию в ствол.
# Оставленная, она уронит первый же чужой запрос слияния, несущий посадки, — и
# это не гипотеза: ровно такой формой 2026-08-16 покраснели два несвязанных
# запроса разом.

# Пустой перечень — нормальное состояние, и сейчас он пуст.
#
# Шесть записей сняты 2026-08-14 как пережившие предмет, и по двум разным
# причинам — обе означают «исключать нечего»:
#
#   ЧЕТЫРЕ описывали снятия, уже влитые в ствол. База сравнения поднялась,
#   и на новой отправке этих снятий не происходит: судимая посадка их не
#   делает. Правило шапки требует снимать такую запись тем же изменением,
#   которое поднимает базу; здесь это сделано отдельно.
#
#   ДВЕ называли файлы, которые в стволе ЖИВЫ, то есть снятия нет вовсе.
#
# Найдено собственным гейтом на запросе слияния волны: он дошёл до вердикта,
# напечатал перепись и назвал каждую запись поимённо. До починки того же дня
# он умирал молча, и «есть находки» было неотличимо от «не дошёл до проверки».

# Седьмая запись снята 2026-09-02 — приспособление фикстуры классов ролей на
# посадке линии modules-5. Истекла ВТОРЫМ из двух способов, названных шапкой:
# линия влита в ствол СХЛОПЫВАНИЕМ, и её посадок в графе не существует.
#
# Гейт называет обе причины и не различает их — это его граница, а не
# небрежность: перепись видит только «ни одна посадка не сработала». Различает
# наблюдение, и признак точный: при исчезнувшем предмете посадка ОСТАЁТСЯ
# достижимой и просто перестаёт делать снятие; при схлопывании её нет в графе
# вовсе, а текст записи приезжает в ствол ФАЙЛОМ внутри схлопнутого коммита —
# то есть запись переживает свой предмет, путешествуя отдельно от него.
#
# Наблюдение, которым установлено (повторяемо):
#   git merge-base --is-ancestor <посадка> origin/main   → нет
#   git merge-base --is-ancestor <посадка> HEAD          → нет
#   git rev-list --parents -n1 <схлопнутый коммит> | wc -w → 2, то есть один
#     родитель; и он стоит на первородительской цепи origin/main
#   посадок линии, достижимых от origin/main             → 0 из 37
#   при этом фикстура в стволе и на линии — ОДИН объект, приспосабливать нечего.
#
# Урок, ради которого абзац оставлен, а не просто снята строка: запись живёт в
# ФАЙЛЕ, а её предмет — в ГРАФЕ, и схлопывание разводит их молча. Поэтому
# предикат снятия пишется в саму запись (он там стоял и сработал дословно), а
# перечень пересматривается на первой же линии, которая унаследовала файл.
