# Осознанные СНЯТИЯ содержимого ствола при переносе — перечень С ПРЕДМЕТОМ.
#
# ЗАЧЕМ ЭТОТ ФАЙЛ. Гейт `drift.sh` стережёт молчаливый откат: ветка, отставшая от
# ствола, возвращает содержимое базы на файлах, которых не касалась, и конфликта
# при этом нет. Но у снятия есть и законный случай: ствол и ветка независимо
# завели ОДИН предмет разными файлами, и в результате обязан остаться один.
# Тогда файл ствола снимается осознанно — и это решение, а не откат.
#
# Различие между ними не выводится из графа: по путям обе картины одинаковы.
# Поэтому решение называется здесь ЯВНО, по одному файлу на запись, с причиной.
#
# КАК ЭТО ЧИТАЕТСЯ ГЕЙТОМ:
#   находка есть, строки нет   → ОТКАЗ. Молчаливое снятие не проезжает.
#   находка есть, строка есть  → пропуск, и он печатается: снятие названо решением.
#   строка есть, находки нет   → ОТКАЗ. Записи больше нечего исключать.
#
# Последнее — не придирка. Запись, пережившая свой предмет, прикроет следующее
# снятие, и прикроет молча: гейт останется зелёным ровно на том, ради чего писался.
# Поэтому запись УДАЛЯЕТСЯ тем же изменением, которое поднимает базу сравнения.
#
# Форма записи: <путь> <TAB или пробелы> <причина одной строкой>
# Пропуском засчитывается ТОЛЬКО снятие (результат не несёт файла). Если файл на
# месте, но с другим содержимым, — это не снятие, и запись его не прикрывает.
